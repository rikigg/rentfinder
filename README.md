# RentFinder Mini App

Публичный фронтенд Telegram Mini App (GitHub Pages).

Бэкенд и бот в этот репозиторий **не входят** — API доступен по URL из `deploy.env` (`VITE_API_BASE`).

## Dev

```bash
npm ci
npm run dev
```

## Deploy

Push в `main` → Actions → GitHub Pages  
URL: `https://<owner>.github.io/rentfinder/`
